Stealthicons

A name and a mark for your address

Paste an address (or any text) and get back a five-letter name you can say aloud and an identicon you can recognise at a glance — both computed only from what you typed, nothing stored, nothing sent anywhere.

Waiting for text.

Name
five letters, alternating vowel and consonant, derived from the same hash as the mark — say it aloud to compare two addresses without reading either one in full.
Mark
a symmetric identicon, also derived from the hash — the official size is 8×8.
Original
the mark for your text exactly as typed.
Lowercase-enforced
the mark for your text with every letter forced to lowercase first — shown alongside the original when the address format doesn't clearly make case meaningful, as a hedge against a transcription that changed case.
Every value here is a pure function of the text above — the same input always produces the same name and mark, and nothing you type leaves this page.
